4. Googleability audit

The highest-risk searchable artefacts in the original were the merge-sort number list, the trace-table inputs and output string, the cloze passage, the validation code, and the SQL statement. Each of these has been changed at the level that a search would key on: the entire number list (3a), the input and pad character that change the final string (2d), the full sentence wording of the cloze (4b(ii)), a literal value plus the table and field names (5a, 5b), and the price figures (5c). Remaining verbatim surface is limited to generic theory questions (1c, 2a(ii), 2a(iii), 3b, 3c, 4b(i)) where there is no original-specific answer to leak and varying the wording would not change what is assessed. No scenario preamble survives word for word from the original.
